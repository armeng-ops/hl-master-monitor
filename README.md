# Half-Life & GoldSrc MasterServer Monitor (MSMonitor)

Единый монитор и браузер серверов GoldSrc (Half-Life 1, Counter-Strike 1.6, Adrenaline Gamer, Opposing Force, Day of Defeat, Team Fortress Classic) по протоколам Valve Master Server и A2S_INFO.

Объединяет в одном приложении **полнофункциональный оконный графический интерфейс (GUI)** и **высокоскоростной консольный режим (CLI)**.

Разработано на **Delphi (Object Pascal / VCL)** для Windows.

---

## Ключевые возможности

1. **Избранные серверы (Favorites)**:
   * Выбор одного или нескольких серверов и добавление в избранное кнопкой **`★ В избранное`** или через контекстное меню (правый клик мыши).
   * Избранные серверы **всегда закреплены на самом верху таблицы** независимо от выбранной колонки сортировки.
   * Визуально отмечены звездочкой **`★`** в столбце нумерации и подсвечены элегантным золотисто-янтарным стилем.
   * Фоновый автоматический переопрос избранных серверов каждые **30 секунд**.
   * Сохранение списка избранного в реестре Windows (`HKCU\Software\MSMonitor\Favorites`).

2. **Бесшовное обновление таблицы без мигания и потери данных**:
   * При повторном поиске или автообновлении таблица **не очищается**: существующие строки обновляются на лету (in-place), а новые добавляются в список.
   * Полная поддержка аппаратного DoubleBuffering и троттлинга сортировки (200 мс) для исключения любого мерцания.

3. **Светлый и темный стили оформления (Delphi VCL Styles)**:
   * Поддержка двух встроенных тем: **Светлая (`Windows10`, по умолчанию)** и **Тёмная (`Windows10 Dark`)**.
   * Мгновенное переключение в настройках без перезапуска программы.
   * Тонкая адаптивная подсветка пинга, числа игроков, модов и выделенных строк.

4. **Параллельный опрос всех MasterServer (Multi-Master)**:
   * Все настроенные мастер-серверы опрашиваются одновременно в отдельных потоках.
   * Включены только актуальные общедоступные Master-серверы с быстрым ответом: `ms.cs16.net:27010`, `ms.gs-monitor.com:27010`, `ms.varq.net:27010`, `ms.tsarvar.com:27010`, `master.csmetahook.com:27010`, `masterserver.csboost.eu:27010`.
   * Списки мастер-серверов и фильтров игр легко редактируются прямо в настройках (`TMemo`, по одной строке на запись).

5. **Потоковая проверка серверов на лету (Streaming Pipeline)**:
   * Опрос игровых серверов (A2S_INFO) начинается сразу при нахождении каждого нового сервера, не дожидаясь ответа от остальных мастеров.
   * Многопоточный пул воркеров (до 10 потоков) параллельно собирает актуальные данные.

6. **Единый список серверов со всеми играми и колонкой MasterServer**:
   * Все серверы модов GoldSrc (Half-Life `valve`, Counter-Strike `cstrike`, Adrenaline Gamer `ag`, Opposing Force `gearbox`, Day of Defeat `dod`, Team Fortress `tfc`) собраны в единый список.
   * Отдельная колонка **«Мастер-сервер»** показывает источник сервера с дедупликацией адресов.

7. **Автоматический переопрос серверов в фоне каждую минуту**:
   * Фоновый переопрос всей базы без блокировки интерфейса пользователя.

8. **Умная фильтрация серверов**:
   * Опции «Скрывать пустые (0 игроков)» и «Скрывать неответившие» (включены по умолчанию). Избранные серверы всегда остаются видимыми.

9. **Высокоточный опрос пинга (1–10 потоков)**:
   * Измерение пинга с микросекундной точностью на базе аппаратного таймера Windows API (`QueryPerformanceCounter`).

10. **Быстрое подключение и экспорт**:
    * Автоматический запуск Half-Life или Counter-Strike 1.6 с параметрами подключения `+connect <IP:Port>`.
    * Экспорт текущего списка серверов в форматы CSV или TXT.

## Структура проекта

* **`MSMonitor.dpr`** — Главный файл проекта и единая точка входа.
* **`msmonitor.dproj`** — Проектный файл Embarcadero Delphi.
* **`MSMonitor.rc` / `MSMonitor.RES`** — Ресурсы приложения.
* **`MainForm.pas` / `MainForm.dfm`** — Главное окно монитора серверов.
* **`SettingsForm.pas` / `SettingsForm.dfm`** — Окно настроек мастер-серверов, фильтров и путей к играм.
* **`HLMasterProtocol.pas`** — Сетевой движок протоколов Valve Master Server и A2S_INFO.
* **`MSCliRunner.pas`** — Консольный режим опроса.
* **`Windows10.vsf`** — Светлый стиль VCL.
* **`Windows10Dark.vsf`** — Темный стиль VCL.

## Сборка проекта

### В среде RAD Studio / Delphi:
1. Откройте проект `MSMonitor.dproj` в Embarcadero Delphi (10.3 Rio или новее).
2. Выберите конфигурацию `Release` и платформу `Win32`.
3. Нажмите **Project -> Build MSMonitor** (или `Shift + F9`).
4. Исполняемый файл `msmonitor.exe` будет создан в корне проекта.

### Через командную строку:
```cmd
dcc32.exe -B -Q MSMonitor.dpr
```
